# 🚀 AI-Powered Customer Churn Prediction & Explainable Analytics Dashboard

An AI-powered customer churn prediction application built using **Python, Machine Learning, Streamlit, Plotly, and SHAP**.

The application predicts whether a customer is likely to churn, provides the churn risk, and explains the key factors behind the prediction using Explainable AI.

> **Predict. Explain. Act. Retain.**

---

## 📌 Problem Statement

Customer churn can significantly affect business revenue and customer retention.

Businesses need to identify customers who are likely to leave **before churn happens**, but traditional analysis may not provide real-time predictions or clear explanations.

---

## 💡 Solution

Our application uses Machine Learning to predict customer churn and provides an interactive dashboard for analyzing customer risk.

The system goes beyond prediction by using **SHAP Explainable AI** to show *why* a customer is predicted to churn.

🧠 Explainable AI

The application uses SHAP (SHapley Additive exPlanations) to understand the model's predictions.

Instead of simply saying:

> "This customer may churn."



the system helps answer:

> "Why is this customer likely to churn?"



This makes the prediction more transparent and easier to understand.
